# やること — 期限を守るためのタスク管理

iPhone のホーム画面に追加して使う Web アプリ（PWA）です。App Store も Mac も不要です。

## できること

- **今日** タブ：期限切れのタスクを赤で一番上に表示。「今日やる / 明日に / 日付を選ぶ」でその場で決め直せる
- **予定** タブ：期限つきのタスクを日付ごとに表示
- **やりたい** タブ：期限のない「あれしたい、これしたい」のメモ置き場
- **記録** タブ：期日内に完了できた割合・今週の完了数・連続日数・直近 14 日の完了数グラフと、完了履歴
- 今日完了したタスクは「今日」タブの一番下に折りたたんで表示（チェックを外すと戻せる）
- くり返し（毎日・平日・毎週・毎月）。遅れて完了しても次回は明日以降になる
- ホーム画面アイコンに「期限切れ＋今日」の件数バッジ
- 入力欄でスペースのあとに書くと期限になる：`牛乳を買う 明日 18時`、`歯医者 11/5 15:00`、`ゴミ出し 金曜 !`
- 完了・削除・移動はすべて「元に戻す」が可能
- オフラインでも動作。JSON でバックアップの書き出しと読み込みができる

## iPhone に入れる手順

アプリは https で公開する必要があります。無料の GitHub Pages を使う方法です。

1. https://github.com でアカウントを作る（持っていれば不要）
2. 右上の「＋」→ **New repository**。名前は例えば `yarukoto`、**Public** を選んで作成
3. 「uploading an existing file」をクリックし、このフォルダの次のファイルをドラッグして **Commit changes**
   `index.html` `app.js` `style.css` `sw.js` `manifest.webmanifest` `icon-180.png` `icon-192.png` `icon-512.png`
4. リポジトリの **Settings → Pages** で、Branch を `main`・フォルダを `/ (root)` にして **Save**
5. 1〜2 分待つと `https://<ユーザー名>.github.io/yarukoto/` で開けるようになる
6. iPhone の **Safari** でその URL を開き、共有ボタン →「**ホーム画面に追加**」
7. ホーム画面のアイコンから起動し、右上の設定 →「バッジを有効にする」

> タスクのデータは iPhone の中だけに保存され、GitHub には送られません。
> ただしホーム画面のアプリと Safari のデータは別々なので、**必ずホーム画面から起動して使って**ください。

## 更新するとき

ファイルを直したら GitHub に再アップロードし、`sw.js` の `CACHE = 'yarukoto-v1'` の番号を `v2` のように上げてください。アプリを 2 回起動し直すと新しい版になります。

## 知っておいてほしい制限

- **決まった時刻のプッシュ通知はありません。** iPhone の Web アプリで時刻指定の通知を出すにはサーバーが必要なため、今回はアイコンのバッジで知らせる形にしています。
  毎朝思い出したい場合は、iPhone の「ショートカット」アプリ →「オートメーション」→「時刻」（例: 毎朝 8:00）→「URL を開く」でこのアプリの URL を開くように設定すると、通知の代わりになります。
- データは端末内のみです。機種変更の前などは、設定 →「書き出す」でバックアップしてください。
